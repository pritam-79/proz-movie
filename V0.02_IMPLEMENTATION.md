## 1. Overview & Objectives

PROZ MOVIE v0.02 synthesizes the authorized OTT streaming platform of v0.01 with a private, federated multi-user media library and restricted 18+ ecosystem inspired by the open-source Peek Stash Browser architecture.

### Architectural Commitments:
1. **Preserve Existing v0.01 Features:** All 278 channels, Live TV guide, TMDB, AniList, TVmaze, Watchmode, YouTube, Internet Archive, and Shaka player integrations remain fully functional.
2. **Federated Private Library (Stash GraphQL):** Connects to one or multiple self-hosted Stash daemon instances via official GraphQL endpoints.
3. **Strict Credential Isolation:** Stash server endpoints, internal IP addresses, API keys, and private tokens remain 100% server-side.
4. **Secure Proxy Streaming:** Video chunks and seeking (HTTP 206 Partial Content) are served through `/api/library/stash/proxy-stream`.
5. **Zero Piracy / Legal P2P Only:** The torrent adapter connects exclusively to allowlisted Public Domain and Creative Commons archives.
6. **Strict 18+ Verification:** Server-side verification on all adult requests, zero public adult previews, and strict adherence to content safety.

## 3. Database Migration Specification

The complete schema migration is located at:
`supabase/migrations/20261123_v002_complete_schema.sql`

Key tables introduced:
- `library_servers`: Registry of federated Stash instances.
- `media_libraries`: Partitioned vaults per server.
- `library_sync_jobs`: Sync operations, delta tracking, and error logs.
- `library_items`: Indexed scenes, duration, rating, organized flags.
- `user_groups` & `group_members`: Multi-user permission hierarchy.
- `library_permissions`: Granular read/stream/download permissions.
- `collection_restrictions`: Studio and tag hiding rules.
- `user_ratings`, `user_favourites`, `user_hidden_items`: Isolated user data.
- `playlists` & `playlist_items`: Custom collections and ordering.
- `download_jobs`: Offline download queue and storage accounting.
- `authorized_media_sources`: Allowlist registry for legal P2P.
- `audit_logs`: Administrative actions and session audit trail.

## 4. Security & Compliance Safeguards

1. **Credentials Isolation:** Stash server URLs, internal IP addresses, and API keys are stored in environment variables (`STASH_SERVER_URL`, `STASH_API_KEY`) or encrypted database columns.
2. **Denial-by-Default:** Media items are inaccessible until explicit permission or user group membership is resolved.
3. **No Piracy Indexing:** The torrent module contains an allowlist registry. Non-allowlisted trackers (e.g. public piracy indices) are rejected immediately.
4. **Age Gate:** The 18+ ecosystem requires confirmation of birth year. No adult media cards, thumbnails, or previews are exposed to unverified sessions.

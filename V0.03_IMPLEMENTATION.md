## 1. Core Architectural Shifts in v0.03

PROZ MOVIE v0.03 transforms the platform from a simulated media catalogue into a **real automated content discovery and streaming engine**.

### What v0.03 Delivers Realistically:
1. **No Fake Stash Data:** When Stash is not connected, the UI shows a clean, honest onboarding state: *"Stash is not connected. Connect a private media library to import your own authorized content."*
2. **Real Public Content Ingestion:**
   - **Internet Archive:** Live querying via Archive.org Advanced Search API (`https://archive.org/advancedsearch.php`) and Metadata API (`https://archive.org/metadata/{id}`). Discovers verified public-domain feature films, silent cinema classics, and historical documentaries with playable MP4 files.
   - **PeerTube:** Live querying across federated PeerTube instances (e.g. `peertube.tv`, `framatube.org`) for Creative Commons, openly licensed videos with direct HLS/MP4 streams and creator attribution.
   - **Openverse:** CC media search integration.
3. **Clear Distinction Between Metadata & Playable Media:**
   - **Metadata Titles (TMDB / TVmaze / AniList):** Display full synopses, cast, ratings, and verified watch links via Watchmode/TMDB Watch providers (Netflix, Prime Video, Disney+ Hotstar, JioCinema, Zee5).
   - **Direct Playable Titles (Archive.org / PeerTube):** Feature active "Play Now" controls that stream verified public-domain and Creative Commons MP4/HLS streams directly in Shaka Player.
4. **Rebuilt 18+ Ecosystem:**
   - Independent catalogue architecture with support for creator-authorized, rights-holder, and self-hosted Stash providers.
   - Truthful empty state when unpopulated with real provider onboarding.
5. **Live Provider Health Telemetry:**
   - Active server-side diagnostics (`/api/admin/health`) executing real pings to TMDB, AniList, TVmaze, Watchmode, Internet Archive, PeerTube, Openverse, Cloudflare, Mux, Supabase, and Stash.

## 2. Content Ingestion Pipeline & Lifecycle

```
[ Public APIs / Feeds ] (Archive.org, PeerTube, Openverse)
           │
           ▼
[ Discovery Engine ] ──► Normalizes Metadata & Detects Duplicates
           │
           ▼
[ Ingestion Pipeline ]
   ├── 1. Discovered
   ├── 2. Metadata Imported
   ├── 3. Rights Verified (Public Domain / CC / Open License)
   ├── 4. Media Asset Available (Inspects playable MP4/HLS URL)
   ├── 5. Playback Tested (Streams verified)
   └── 6. Published in Catalog
```

## 3. Database Migration Specification (v0.03)

The PostgreSQL migration `supabase/migrations/20261124_v003_complete_schema.sql` extends the database with:
- `content_sources`: Registry of discovery providers (Archive.org, PeerTube, Openverse, Stash).
- `discovered_content`: Ingested records with raw metadata and source references.
- `content_import_queue`: Workflow state tracker with review statuses.
- `content_rights`: License categorization (`public_domain`, `creative_commons`, `creator_authorized`).
- `provider_health_logs`: Real-time health check history and latency.
- `adult_providers`: Registry of adult media connectors and status.
